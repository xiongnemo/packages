Nemo's Packages

Indices only: every package is fetched from its GitHub Release. Two channels, each on its own: subscribe to stable, nightly or both. On Windows, use the Scoop bucket instead:

scoop bucket add nemo https://github.com/xiongnemo/windows-binaries-scoop-bucket

stable

Releases: an exact version tag, published as a release.

apt

sudo curl -fsSLo /usr/share/keyrings/nemo.gpg https://package.anzupop.com/keys/nemo-packages.gpg
echo "deb [signed-by=/usr/share/keyrings/nemo.gpg] https://package.anzupop.com/apt stable main" | sudo tee /etc/apt/sources.list.d/nemo-stable.list
sudo apt update

dnf

sudo curl -fsSLo /etc/yum.repos.d/nemo-stable.repo https://package.anzupop.com/rpm/nemo-stable.repo

apk

wget -qO /etc/apk/keys/nemo-packages.rsa.pub https://package.anzupop.com/keys/nemo-packages.rsa.pub
echo "https://package.anzupop.com/apk/stable" >> /etc/apk/repositories
apk update

MacPorts

sudo curl -fsSLo /opt/local/share/macports/nemo-macports.pub https://package.anzupop.com/keys/nemo-macports.pub
echo /opt/local/share/macports/nemo-macports.pub | sudo tee -a /opt/local/etc/macports/pubkeys.conf
# then add this line above the [default] line of /opt/local/etc/macports/sources.conf:
https://package.anzupop.com/macports/stable/ports.tar
sudo port sync

nightly

Prereleases: every push to a project's main branch, versioned as a prerelease of the next release (1.4.3~pre-1, apk 1.4.3_pre-r1).

apt

sudo curl -fsSLo /usr/share/keyrings/nemo.gpg https://package.anzupop.com/keys/nemo-packages.gpg
echo "deb [signed-by=/usr/share/keyrings/nemo.gpg] https://package.anzupop.com/apt nightly main" | sudo tee /etc/apt/sources.list.d/nemo-nightly.list
sudo apt update

dnf

sudo curl -fsSLo /etc/yum.repos.d/nemo-nightly.repo https://package.anzupop.com/rpm/nemo-nightly.repo

apk

wget -qO /etc/apk/keys/nemo-packages.rsa.pub https://package.anzupop.com/keys/nemo-packages.rsa.pub
echo "https://package.anzupop.com/apk/nightly" >> /etc/apk/repositories
apk update

MacPorts

sudo curl -fsSLo /opt/local/share/macports/nemo-macports.pub https://package.anzupop.com/keys/nemo-macports.pub
echo /opt/local/share/macports/nemo-macports.pub | sudo tee -a /opt/local/etc/macports/pubkeys.conf
# then add this line above the [default] line of /opt/local/etc/macports/sources.conf:
https://package.anzupop.com/macports/nightly/ports.tar
